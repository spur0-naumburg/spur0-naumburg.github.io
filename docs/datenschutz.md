## 4. Kommentarfunktion über Giscus

### 4.1 Welche Daten werden für welchen Zweck verarbeitet?

Auf einzelnen Unterseiten unserer Website stellen wir eine Kommentarfunktion über den Dienst Giscus zur Verfügung.

Giscus ist ein Open-Source-Kommentarsystem, das die GitHub-Discussions-Funktion zur Speicherung und Verwaltung von Kommentaren verwendet.

Die Kommentarfunktion wird beim Aufruf der entsprechenden Unterseite automatisch geladen und angezeigt.

Hierbei wird eine Verbindung zu den Servern von Giscus und GitHub hergestellt. Dabei können insbesondere folgende Daten verarbeitet werden:

* IP-Adresse
* Datum und Uhrzeit des Zugriffs
* Informationen über den verwendeten Browser
* Informationen über das verwendete Betriebssystem
* Technische Verbindungsdaten
* Informationen, die für die Bereitstellung und Anzeige der Kommentarfunktion erforderlich sind

Die Kommentarfunktion dient dazu, Besuchern unserer Website den Austausch über unsere Vereinsaktivitäten, Veranstaltungen und Veröffentlichungen zu ermöglichen.

Für das Verfassen und Veröffentlichen von Kommentaren ist bei der regulären Giscus-Integration eine Autorisierung über ein GitHub-Konto erforderlich. 
Die Anmeldung erfolgt über GitHub.

Wenn Sie einen Kommentar veröffentlichen, werden die von Ihnen eingegebenen Inhalte sowie die zur Zuordnung erforderlichen Informationen in GitHub Discussions gespeichert. 
Die Kommentare können öffentlich sichtbar sein.

Bitte veröffentlichen Sie keine vertraulichen oder besonders schützenswerten personenbezogenen Daten in den Kommentaren.
